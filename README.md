# CCNA 200-301 Study Journey

Documenting my path toward the Cisco Certified Network Associate (CCNA) 200-301 certification — diagnostic testing, weekly theory deep-dives, and hands-on Packet Tracer labs with real troubleshooting scenarios.

## Why this repo exists

This is a working log of my CCNA prep, built to:
- Track measurable progress against the official exam blueprint
- Practice explaining networking concepts clearly (a skill that matters as much as knowing them)
- Build a portfolio of hands-on lab work and troubleshooting reasoning for future employers

## Study Approach

- **Weekly cycle:** alternating between theory/learning weeks and hands-on Packet Tracer lab weeks
- **Monthly practice quizzes** to benchmark progress across all six blueprint domains
- **Diagnostic-driven:** starting from a baseline skills assessment and prioritizing weak areas first
